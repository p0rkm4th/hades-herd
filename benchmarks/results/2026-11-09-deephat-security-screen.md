# DeepHat-V1-7B security screen — 2026-11-09

DeepHat was evaluated as the distinct cybersecurity/DevOps fine-tune candidate after the other installed candidates failed. The model came from a static GGUF quant of the official [DeepHat-V1-7B](https://huggingface.co/DeepHat/DeepHat-V1-7B) source. Quant repository: [mradermacher/DeepHat-V1-7B-GGUF](https://huggingface.co/mradermacher/DeepHat-V1-7B-GGUF/tree/dcfd1c6fa3bfae69365e898cc394d3227e0a95a2). The upstream source declares Apache-2.0 plus an additional DeepHat license extension; review both before any reuse.

The isolated Ollama 0.40.15 test used Flash Attention and Q8_0 KV cache; backend logs confirmed both. A short warmup took 3.38 s. The existing combined synthetic Nmap/SSH/Sigma fixture then completed in 33.73 s (365 prompt tokens; 900 generated tokens, reaching the configured output cap). It failed independent checks: it attributed Apache CVE-2021-41773 to OpenSSH 8.2p1, invented an OpenSSH/password-authentication CVE explanation, omitted the required conclusion that the observed Nginx service is not affected by that Apache CVE, and returned an invalid Sigma rule (wrong product and no exact `Failed password` match). It also produced repeated, unrequested pentest-tool/methodology advice. No commands, network actions, or tools were executed.

The original model card advertises 131,072 context, but this GGUF declares `qwen2.context_length=32768`; despite requesting 131,072 in both the Modelfile and request, Ollama actually allocated 32,768. `ollama ps` reported 100% GPU; one GPU used about 5,403 MiB, with no CPU offload. Q8_0 KV used 952 MiB at the actual 32K allocation. This artifact cannot satisfy Hermes' 64K context floor. Tool-call behavior was not tested after the security-accuracy failure.

The download, GGUF import, logs, and isolated Ollama server were removed after the failed screen; production Ollama/Herd and all model defaults were untouched. **No tested candidate currently qualifies for SECURITY-LAB.** Private response, metrics, exact checks, and cleanup evidence are in the HADES infra acceptance record.
